Добавляет на страницы плейлистов, альбомов и исполнителей дополнительную информацию:
- Полная дата релиза (+ иконка если это новый релиз) 
- Количество треков
- Порядковый номер трека в плейлисте
- Дата добавления трека в плейлисте
- Дата создания плейлиста
- Суммарная длительность всего плейлиста
- Просмотр других плейлистов от автора при нажатии на его имя
- Иконка которая указывает на то, что плейлист приватный
- Жанр альбома и артиста
- Изменение количества ежемесячных прослушиваний на странице артиста
- Иконка если артист - нейросеть
- Описание артиста
- Количество треков и альбомов артиста
- Дата рождения и кончины артиста
- Количество лайков артиста
- Настоящее имя артиста
- Страны исполнения артиста
- Видеоклип в шапке артиста
